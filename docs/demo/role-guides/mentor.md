# Role Guide: Mentor

This guide outlines the system walkthrough for a Mentor account.

---

## 1. First Login Experience

* **Landing Interface**: Logs into a read-only support dashboard (`/dashboard`).
* **Visual Widgets**:
  * **Schedules Timeline**: Vertical list of classes and sessions they are assigned to monitor.
  * **Student Progress Summaries**: Quick preview of student performance in active cohorts.

---

## 2. Navigation Tour

* **Step 1: Dashboard (`/dashboard`)**: Preview upcoming class schedules.
* **Step 2: Class Directory (`/academic/classes`)**: View class cohorts, rosters, and assignments.
* **Step 3: Session Calendar (`/academic/sessions`)**: View scheduled lectures.
* **Step 4: Attendance Explorer (`/academic/attendance`)**: View (but not edit) class attendance records.

---

## 3. Typical Daily Workflow

1. Log in to check upcoming class schedules.
2. Join active WebRTC live sessions to monitor discussions, manage chats, and answer questions.
3. Review student attendance logs after class ends.
4. Review student homework assignments and check who needs academic support.

---

## 4. Permissions Summary

### Things They Can Create
* *None* (Read-only support role).

### Things They Can Edit
* Personal profile configurations.

### Things They Can View
* Class details, cohort schedules, enrollment lists.
* Attendance logs (read-only).
* Shared recordings.

### Things They Cannot Access
* Financial ledger or invoice configurations.
* Grade modification workflows.
* Launching live sessions or starting recording captures.
* Creating assignments, assessments, classes, or inviting users.
